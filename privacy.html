Privacy Policy

Rclone Backup is a personal application used by the account owner to back up files to their own Google Drive account.

Google Drive Data

The application accesses Google Drive only after explicit authorization by the Google account owner.

Access is used only to create, upload, update, and manage backup files in the authorized Google Drive account.

Data Sharing

Google Drive data accessed by this application is not sold, shared, transferred, or disclosed to third parties.

Data Storage

This application does not operate an external server for storing user data. Files are transferred using rclone between the user's computer and the user's Google Drive account.

Authorization

The user may revoke the application's Google Drive access at any time through their Google Account security settings.

Purpose

This application is intended for personal backup purposes only and is not offered as a public service.
